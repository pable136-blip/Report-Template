# 부서 통합 업무보고
여러 부서가 추진사항을 공동 입력하고 현황·슬라이드 보고서로 확인하는 웹 앱입니다.

## 주요 기능
- 부서별 사업 입력, 1초 후 자동 저장, 3초 간격 현황 갱신
- 업무명·분야 설정, 부서·분야별 필터
- 표지·목차·본문 슬라이드, 전체 분야 보고에만 목차 표시
- 보고서에서 텍스트·이미지 편집, 붙여넣기·교체·삭제·이동·크기 조절
- 9종 글꼴, 제목·본문별 크기·굵기·색상, 4종 디자인
- 전체화면 발표 및 클릭/키보드 이동, 인쇄·PDF 저장
- 복수 첨부파일 업로드·다운로드·교체·삭제

## 실행
Node.js 22.13 이상, pnpm(package.json에 지정된 버전), React / TypeScript / Vinext, Cloudflare D1 및 R2가 필요합니다.
순서: pnpm install --frozen-lockfile → pnpm dev 또는 pnpm build.
D1/R2 바인딩과 마이그레이션 설정은 [개발 환경](docs/STARTER.md)을 참고하세요.
다른 계정에서 이어서 작업하려면 [인수인계](docs/HANDOFF.md)를 먼저 읽어 주세요.
